# 🌐 IP Info Viewer

![License](https://img.shields.io/badge/license-MIT-blue)
![Language](https://img.shields.io/badge/language-C%23-green)

Простая и удобная программа на C# для получения информации о сетевых адресах вашего компьютера.

## ✨ Возможности

✅ Показывает локальный IP адрес (IPv4 и IPv6)  
✅ Отображает имя компьютера в сети  
✅ Получает публичный (глобальный) IP адрес  
✅ Показывает геолокацию по IP  
✅ Красивый интерфейс в консоли
